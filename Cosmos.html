Cosmos - Cutscene Design and Gameplay Events

Opening Cutscene + Ending Cutscene

Dynamic Main Menu + Idle Scene

Plays when there is no input from the player

A retro-inspired game made in Unity 2D, focused on modular systems, bullet-hell combat, and responsive game feel. The project evolved from prototype to MVP with scalable architecture and configurable enemy behavior.

  • Code
  • Documentation

Project Highlights

Dynamic Main Menu: A fully animated main menu created using Timeline, featuring smooth animations and cinematic motion.

Camera Mode Switching: A seamless transition between first-person and third-person cameras using Cinemachine, demonstrating flexible camera control and blending.

Gameplay Trigger Event: A gameplay-triggered cinematic moment implemented using Timeline and Cinemachine extensions to execute logic directly within the scene

Custom Fade In and Fade Out Transitions: A custom fade-out transition animated entirely in Timeline to support cinematic scene changes.

Spaceship Flight Gameplay: Spaceship flight gameplay featuring pitch, yaw, and roll controls coded in C#, paired with an immersive Cinemachine camera setup.

Camera Shake via Timeline Extensions: An example of a Timeline extension used to generate camera shake during a cutscene, enhancing impact and immersion.

Hype Space Travel Sequence: A hyperspace travel animation and scene transition created using Timeline and Cinemachine to deliver a cinematic gameplay moment.
